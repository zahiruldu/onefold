onefold

Zero-dependency TypeScript UI framework. Fine-grained signals, real DOM, secure by default. Everything you need, nothing you don't.

Quickstart

import { createSignal, html, mount } from 'onefold';

function Counter() {
  const count = createSignal(0);

  return html`
    <div class="counter">
      <h2>${`\${() => \`Count: \${count()}\`}`}</h2>
      <button onclick=${`\${() => count.set(c => c + 1)}`}>+</button>
      <button onclick=${`\${() => count.set(0)}`}>Reset</button>
    </div>
  `;
}

mount(Counter(), document.getElementById('app')!);

That's a complete, reactive, type-safe component. No build step required, no JSX, no virtual DOM.

Core Concepts

Signals (Reactivity)

Signals are reactive values. Reading a signal inside a closure creates a subscription — when the signal changes, only that specific binding updates.

const name = createSignal('World');
const upper = createComputed(() => name().toUpperCase());

// Only the text node updates when name changes — nothing else re-renders
html`<h1>${`\${() => \`Hello, \${upper()}\`}`}</h1>`

Templates (Rendering)

html is the one templating primitive. Write HTML naturally with ${`\${}`} for dynamic values.

// Static values
html`<div class="card">${`\${title}`}</div>`

// Reactive values (wrap in a closure)
html`<div class=${`\${() => isActive() ? 'active' : ''}`}>...</div>`

// Event handlers
html`<button onclick=${`\${() => count.set(c => c + 1)}`}>Click</button>`

// Lists
html`<ul>${`\${() => items().map(i => html\`<li>\${i.name}</li>\`)}`}</ul>`

// Conditionals
html`<div>${`\${() => loggedIn() ? Dashboard() : LoginForm()}`}</div>`

Components

A component is just a function that returns a Node. No classes, no decorators, no lifecycle methods.

interface Props { label: string; }

function Toggle({ label }: Props): Node {
  const on = createSignal(false);
  return html`
    <button onclick=${`\${() => on.set(v => !v)}`}>
      ${`\${() => \`\${label}: \${on() ? 'On' : 'Off'}\`}`}
    </button>
  `;
}

Scoped CSS

The css tagged template scopes styles to a component. No leaking, no naming collisions.

const styles = css`
  .card { background: white; border-radius: 8px; padding: 16px; }
  .title { color: #333; font-size: 20px; }
`;

function Card() {
  return html`<div class=${`\${styles.scope}`}>
    <div class="card"><h2 class="title">Scoped!</h2></div>
  </div>`;
}

Philosophy

  • One way to do things. One templating primitive (html), one reactive model (signals), one list pattern (.map() or VirtualList). No second API to learn "for advanced use cases."
  • Zero runtime dependencies. The onefold package ships only its own code. Nothing else runs in your users' browsers.
  • Functions, not classes. Components are functions returning Nodes. No decorators, no lifecycle methods, no class hierarchies.
  • Security by default. Text goes through textContent, never innerHTML. URLs block javascript:/data: schemes. Sanitizer strips scripts. Trusted Types supported.
  • Tree-shake everything. Import only what you use. A counter app is 3kb. A full enterprise app with every feature is 13kb.
  • AI-friendly. AGENTS.md tells any AI assistant how to write correct onefold code. Component metadata makes apps machine-readable.
